Project Title: ServerLab
Description: a minimalist resources specific grafana like application. this application monitor homelab server resource in cool simple visualizer


Features:

1. User Watcher: it monitors user access login to your server. the user, timestamp, geolocation,
2. Resources Monitor: live visual graph of CPU, GPU, Memory Usage, Server Temperature, Network speed
3. Server Lobby: this is the main entry point that overview number of applications installed, services, website hosted and databases. it detects applications hosted and has an icon if it is in services or in docker. user can also manually add to list if it is not detected. each items in card ui with the title name, short description what this application/service used for. then how to open a url. it also show what database installed like mysql, postgres
4. Application resources usage: in a ranking nice bar percentage visual + actual size in memory consumption for each application
